Reusable Intel macOS cryptography wheel with statically linked OpenSSL LTS.

This is a companion build dependency, not a new application release or an
upstream cryptography/OpenSSL release. The asset includes its source/build-input
manifest, component SBOM and original toolchain inventory. Its GitHub provenance
attestation must verify this repository's main-branch validation workflow on a
GitHub-hosted runner before reuse. Consumers rerun native and vulnerability checks.

Source inputs and verification policy: [Intel dependency build](https://github.com/ricardomartins-gravitee/openmaskit-companion/blob/main/docs/intel-wheel.md).
